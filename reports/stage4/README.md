# Verification evidence

JSON records and execution logs in this directory describe the completed Stage 4
verification. Their timestamps, source snapshots and checksums identify that run;
they are retained as historical evidence. The complete pre-editorial working tree,
including the report and presentation then reviewed, is preserved in
[the baseline archive](../archive/stage4_before_editorial_refinement.zip).

The [statistical audit](statistical_audit.md) explains the methods and numerical
checks. Current document generation, editorial validation and layout review are
reported separately in [Stage 5](../stage5_refinement.md). Reproduction commands
are in [the reproduction guide](../reproducibility.md).
